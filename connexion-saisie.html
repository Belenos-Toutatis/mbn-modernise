Connexion automatique à MBN

Tapez votre phrase de passe : elle est demandée une fois à chaque ouverture de Chrome, puis la connexion se fait sans clic jusqu'à sa fermeture.

Connexion automatique à MBN

L'extension choisit votre profil sur MBN, puis tape elle-même vos identifiants sur la page de connexion de l'académie : plus aucun clic.

Le profil sera celui que vous validerez sur l'écran de connexion de MBN.

Protection sur cet ordinateur
Enregistré dans Chrome. Chiffré, dans votre profil Chrome sur cet ordinateur, avec une clé tirée de votre phrase de passe et jamais écrite sur le disque : une copie du profil ne suffit pas à retrouver votre mot de passe. Rien n'est écrit dans le dossier de l'extension, ni envoyé ailleurs qu'à la page de connexion de l'académie.
Une fois la phrase tapée, et jusqu'à la fermeture de Chrome, toute personne qui utilise votre session se connecte à votre place. Phrase oubliée : il suffit de réenregistrer vos identifiants.
Enregistré dans Chrome. Chiffré, dans votre profil Chrome sur cet ordinateur, au même endroit que vos mots de passe enregistrés. Rien n'est écrit dans le dossier de l'extension, ni envoyé ailleurs qu'à la page de connexion de l'académie.
Sans phrase de passe, la clé est rangée dans le même profil que les données : seul le chiffrement du disque protège d'une copie. Toute personne qui utilise ce profil Chrome se connecte à votre place.
