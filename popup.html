Pour l'installer :
  1. dans le dossier de l'extension, lancez git pull (ou téléchargez l'archive ZIP du dépôt) ;
  2. dans chrome://extensions, cliquez sur la flèche de rechargement de « MBN modernisé » ;
  3. rechargez les pages MBN ouvertes.

Apparence

Rafraîchissement automatique

Jamais pendant une saisie ou la rédaction d'un message.

Capture de structure anonymisée

Relève la mise en page de l'onglet affiché (balises, classes, tailles) sans aucun texte de la page. Le résultat reste sur votre ordinateur : relisez-le ci-dessous avant de le transmettre.
